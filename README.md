# PROLOGUE – The Reading Club of LBSITW

## About

PROLOGUE is a responsive website created for the Reading Club of LBS Institute of Technology for Women (LBSITW).

The website presents the club's purpose, activities, events, gallery, membership registration, and contact information.

## Features

- Responsive website design
- Home, About, Why Join, Activities, Events, Gallery and Membership sections
- Interactive membership registration form
- JavaScript form validation
- Image gallery
- Mobile-friendly layout
- GitHub Pages hosting

## Technologies Used

- HTML5
- CSS3
- JavaScript
- GitHub Pages
